# 《军工复合体：喷气时代》游戏设计文档（草案 v0.1）

> Military-Industrial Complex: Jet Age — Game Design Document (Draft)

## 1. 核心概念

玩家扮演一家**飞机制造商**，研发科技树、亲手绘制翼型、做风洞实验，用游戏内置的模拟器估算飞机性能，再和本国史实中存在的飞机项目竞标，赢得订单。

- **核心定位**：严格扮演制造商。设计是主角，战争是检验场。
- **参考作品**：Automation（设计 + 经营）、Rule the Waves（历史约束下的设计 + 战争反馈）、Kerbal Space Program（物理即玩法）。
- **市场空白**：以"制造商"为主角、又有扎实物理设计的军用飞机游戏，目前基本没有成熟作品。

## 2. 核心循环

```
设计 → 模拟估算 → 风洞 → 原型试飞 → 竞标 / 外销 → 实战（AI 模拟）→ 声誉与新需求 → 再设计
```

### 2.1 不确定性是核心机制

| 阶段 | 成本 | 作用 |
|---|---|---|
| 内置模拟器 | 低、快 | 给出带误差范围的性能估算（如最大速度 1.8 ± 0.15 马赫） |
| 风洞实验 | 中 | 缩小误差，发现隐藏问题（如大迎角失速） |
| 原型试飞 | 高 | 暴露颤振、尾旋、发动机喘振等问题 |
| 竞标 | — | 在数据不确定时承诺性能：赌对了赢，吹过头了被罚 |

## 3. 物理与性能估算

不使用实时 CFD，而采用工程概念设计阶段的半经验方法：

| 模块 | 方法 |
|---|---|
| 2D 翼型 | 面元法 + 边界层（类 XFOIL） |
| 3D 机翼 / 全机 | 涡格法 VLM（类 AVL） |
| 阻力、超音速波阻 | DATCOM、Raymer 经验公式，面积律估算 |
| 重量、航程、爬升、盘旋 | Raymer / Roskam 概念设计公式 |
| 发动机 | 参数化循环分析或供应商目录 |

- 翼型绘制提供两种模式：参数化（NACA、CST）给新手，自由绘制给硬核玩家。
- 跨音速和超音速区间：精度只求"可信、趋势正确"。

## 4. 从物理数据到作战指标

| 作战指标 | 来源 |
|---|---|
| 超视距能力（BVR） | 雷达距离、导弹性能、最大速度、升限 |
| 近距格斗能力（WVR） | 持续 / 瞬时盘旋率、单位剩余功率 Ps、推重比 |
| 作战半径与载弹量 | 燃油系数、耗油率、挂架 |
| 生存力 | 雷达反射面积、速度、冗余设计 |
| 出勤率 | 可靠性、每飞行小时维护工时 |
| 成本 | 单价、全寿命成本 |

Boyd 的能量机动理论（Ps 图）是连接气动模拟和空战结果的桥梁。

## 5. 战争系统（AI 操作，可复用现有战争系统）

### 5.1 空战结算（每回合 / 每天）
1. 航程检查 → 有效架次
2. 出勤率 = 部署数 × 完好率
3. BVR：发现概率 f(距离, 雷达, RCS)；命中概率 f(距离, 导弹代际, 目标机动)
4. 格斗：按格斗交换比结算（性能差 × 飞行员素质）
5. 对地任务：突破拦截和地面防空后按载弹量结算
6. 损耗：战损 + 事故 + 维修

任务类型：空优 / 巡逻、截击、护航、CAS、遮断 / 轰炸、侦察（可选）。

### 5.2 地面战
- 战线区段模型：每段只有双方地面强度两个数字，用兰彻斯特方程或强度比推进。
- 空军通过 CAS（削弱强度）、遮断（削弱补给）、空优（使前两者生效）影响地面。
- 也可使用"史实剧本 + 偏移"模式。

### 5.3 制造商在战争中的参与
- 紧急增产（承担债务和战后产能过剩风险）
- 战场改进 / 快速改型（如越战后 F-4E 加装机炮）
- 派驻技术代表（提高出勤率、收集数据）
- 战时交付优先级（本国 vs 出口客户）
- 观战模式（可视化战况）
- 可读战报：明确告诉玩家输在哪里

## 6. 外销与地缘政治

流程：**选择市场和方案 → 政府审批 → 竞标 → 交付与售后**

- 政府审批由外交关系和技术等级决定，可通过游说影响，可能突然禁运。
- 出口降级版、融资、补偿贸易、技术转让。
- 不同市场需求不同：廉价耐用 vs 高性能 + 技术转让。
- 售后（零件、维修、弹药）就是影响力。
- 风险：武器被用来打盟友、技术泄露、客户政变。
- 实战表现影响国际声誉（如 1967 年后幻影 III 订单大增）。

## 7. 可选国家与制造商类型

| 类型 | 代表 | 玩法特点 |
|---|---|---|
| 私营公司 | 美国、法国、英国、瑞典 | 竞标、外销、现金流、破产风险 |
| 国有设计局 | 苏联、中国 | 争夺国家任务，靠政治与预算，无出口权 |
| 跨国财团 | 欧洲联合项目 | 多国分工、政治妥协 |
| 许可生产 / 追赶型 | 日本、印度、以色列 | 仿制 → 许可生产 → 自主研发 |

## 8. 试飞员空战演习

- 玩家可操控厂商试飞员参加对比试飞 / 演习，表现影响销售。
- 加成有上限（约 ±10–15%），保证设计比操作更重要。
- 提供 AI 代飞选项。
- 可嵌入 JSBSim 作为飞行动力学内核。

## 9. 平衡要点
- 防止玩家用后见之明碾压历史：科技树、风险、成本、制造能力约束；评标综合性能、价格、进度、风险、政治。
- 空军对地面战的影响要明显但有上限。
- 数量也有自己的质量：贵而出勤率低的飞机未必赢。

## 11. 法律注意
- 避免使用真实公司名称和商标（Lockheed、Boeing、Dassault、Skunk Works 等），竞争厂商可虚构化。
- 定名前检查 Steam 同名、商标和域名。

## 12. MVP 范围
- 一个国家、一个时代：美国 1945–1960 喷气时代
- 2D 翼型 + 涡格法 + 经验公式
- 5–8 个史实招标项目
- 先验证"设计 → 测试 → 投标"循环是否好玩
