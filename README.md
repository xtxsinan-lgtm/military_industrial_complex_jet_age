# Military-Industrial Complex: Jet Age

《军工复合体：喷气时代》—— 一款战斗机制造商经营与设计模拟游戏。

Run an aircraft company in the jet age: research a tech tree, draw your own airfoils, run wind-tunnel tests, estimate performance with a built-in simulator, and compete against historical aircraft programs for military contracts and export deals.

## Status

Early concept stage. See the [game design document](docs/game_design.md).

Aerodynamics prototype (AeroSandbox, validated on the F-86E): see [docs/aero_prototype.md](docs/aero_prototype.md).
